# 📊 ElectroTech Manufacturing Analytics

> An interactive Power BI dashboard for analyzing manufacturing performance, production trends, quality metrics, downtime, and operational efficiency.

## 🎯 Project Overview

This project analyzes manufacturing data to provide a clear view of **production performance and operational efficiency**.

The dashboard transforms raw manufacturing data into interactive visualizations and KPIs that can help identify production trends, quality issues, and downtime patterns.

## 💡 Objectives

* Monitor overall production performance
* Analyze production trends over time
* Track quality and defect rates
* Identify downtime patterns
* Compare operational performance
* Generate actionable business insights

## 🛠️ Tools & Technologies

* **Power BI** — Dashboard & visualization
* **Power Query** — Data cleaning and transformation
* **DAX** — Calculated measures and KPIs
* **Data Modeling** — Relationships and analytical model
* **Excel / CSV** — Source data

## 📊 Dashboard Features

* 📈 Production trend analysis
* 🏭 Manufacturing performance monitoring
* ⏱️ Downtime analysis
* ⚙️ Operational efficiency metrics
* 🛑 Defect and quality analysis
* 📊 KPI cards
* 🔎 Interactive filters and slicers
* 📅 Time-based analysis
* 📋 Business-focused reporting

## 🚀 How to Use

1. Download the `.pbix` file from the `dashboard/` folder.
2. Open it using **Microsoft Power BI Desktop**.
3. Refresh the data if required.
4. Use the slicers and filters to explore different dimensions.
5. Navigate through the dashboard pages to analyze production, quality, and operational metrics.
